# Day 14 — Collections Framework-I

# Theory
1. Collection Framework

The Java Collection Framework provides interfaces and classes to store and manipulate groups of objects.

2. List

An interface in the Collection Framework.

Maintains insertion order.

Allows duplicate elements.

Supports index-based access.

3. ArrayList

Uses a dynamic array.

Maintains insertion order and allows duplicates.

Provides fast index-based access.

Common methods: add(), get(), set(), remove(), size().

4. LinkedList

Uses a doubly linked list.

Maintains insertion order and allows duplicates.

Efficient for adding or removing elements at the ends.

Methods: addFirst(), addLast(), removeFirst(), removeLast().

5. Vector

Uses a dynamic array.

Maintains insertion order and allows duplicates.

Synchronized, unlike ArrayList.

Mostly used in legacy code.

6. Iterator

Used to traverse collection elements one by one.

hasNext() — checks whether another element exists.

next() — returns the next element.

remove() — removes the current element safely during iteration.
