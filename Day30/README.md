## Introduction
Git is a distributed version control system used to track changes in source code. GitHub is a cloud-based platform used to store and manage Git repositories online.

## Topics Covered

### 1. Git
Git is a version control system that helps developers track code changes and manage different versions of a project.

### 2. Repository
A repository (repo) is a storage location where project files and their version history are maintained.

### 3. Commit
A commit is a snapshot of changes made to a project. It saves the current changes in Git history.

### 4. Branch
A branch is a separate line of development that allows developers to work on new features without affecting the main branch.

### 5. Merge
Merge is used to combine changes from one branch into another branch.

### 6. Pull
Pull is used to download the latest changes from a remote repository and merge them into the local repository.

### 7. Push
Push is used to upload local commits to a remote repository such as GitHub.

### 8. Pull Request
A Pull Request (PR) is a request to merge changes from one branch into another branch on GitHub. It allows team members to review code before merging.

### 9. .gitignore
The `.gitignore` file tells Git which files and folders should be ignored and not tracked.

## Git Commands

| Command | Description |
|---|---|
| `git init` | Initialize a Git repository |
| `git status` | Check repository status |
| `git add .` | Stage all changes |
| `git commit -m "message"` | Save changes |
| `git branch` | List branches |
| `git branch feature` | Create a branch |
| `git checkout feature` | Switch branch |
| `git merge feature` | Merge a branch |
| `git pull origin main` | Get latest changes |
| `git push origin main` | Upload changes |
| `git log` | View commit history |
| `git remote -v` | View remote repository |
